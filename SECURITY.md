# Security scope

This is an experimental historical compatibility recipe, not a maintained
security distribution. It applies one specific upstream mitigation to an EOL
PHP release and retains historical dependencies. No support SLA is offered.

Do not publish a new vulnerability, exploit, secret, production log or customer
identifier in a public issue. Report PHP engine vulnerabilities through the
[PHP security process](https://www.php.net/security/), and dependency issues to
the corresponding upstream project. No private reporting address for this
community recipe has been established. Enable GitHub private vulnerability
reporting before offering it as a reporting channel.

For non-sensitive recipe defects, open an issue with sanitized reproduction
steps, source checksums and environment versions. A successful build or smoke
test does not establish that the resulting system is secure.
